# Athena Roadmap

## Priority order

1. Foundation & Infrastructure
2. Email Intelligence Agent
3. Calendar Consensus Agent
4. Meeting Intelligence Agent
5. Weekly Review & Daily Briefing
6. Content Pipeline Agent
7. Personal Shopper Agent
8. Mac Mini Migration

## Phase map

- Phase 1 (Week 1): Foundation setup
- Phase 2 (Week 2-3): Core productivity agents (email + calendar)
- Phase 3 (Month 2): Meeting intelligence, content pipeline, review loops
- Phase 4 (Month 3+): Lifestyle automation
- Phase 5 (Hardware event): Always-on migration to Mac Mini

## Linear execution shape

Linear workspace should mirror the same hierarchy:

- Project: `Personal AI Agent Infrastructure`
- Parent issues: Epic-level workstreams (`E1` to `E8`)
- Child issues: Story/Feature groups (`Sx.y`)
- Grandchild issues: task-level execution (`Tx.y.z`)

## Working agreements

- Athena planning artifacts are the source of truth.
- Linear is execution telemetry and collaboration surface.
- Sync process should be safe to run multiple times (idempotent behavior preferred).
